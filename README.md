# Afterjot for Mac

Public downloads and signed Sparkle update feed for Afterjot. Application source code is maintained separately in a private repository.

## Download

[Download Afterjot 0.1.0 (9)](https://github.com/alecramos-sudo/afterjot-releases/releases/download/v0.1.0-9/Afterjot-0.1.0-8.zip)

Requires macOS 14 or later. Supports Apple Silicon and Intel Macs. The app is signed with Developer ID and notarized by Apple. Unzip it and move Afterjot to Applications before opening it.

Build 9 is the current release. It fixes a macOS 15 crash when Today includes overdue tasks.

## Updates

Afterjot uses Sparkle for signed updates. Enable automatic update checks in Afterjot Settings or choose **Check for Updates…** from the app menu. Installation follows your Sparkle preferences and may ask for confirmation.

The GitHub feed is https://alecramos-sudo.github.io/afterjot-releases/appcast.xml.

Build 4 still checks the original update feed. The next release will be published to that feed as well so existing installations can move to the GitHub feed. The feed in this repository currently mirrors the original signed feed unchanged, including its original download URLs.

This repository contains distribution files only. GitHub's automatically generated “Source code” archives contain these public distribution files, not Afterjot's application source.
